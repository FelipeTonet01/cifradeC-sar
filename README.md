# 🔐 CryptoCaesar - Algoritmo de Criptografia Simétrica

Este projeto é uma implementação prática de um **algoritmo de substituição por deslocamento (Cifra de César)**, desenvolvida como parte do estudo de criptografia e segurança de redes.

## 📖 Contexto Acadêmico
O algoritmo foi desenvolvido com base nos conceitos apresentados no livro:
**STALLINGS, William. Criptografia e segurança de redes: princípios e práticas.**

O projeto foca em dois pilares descritos na obra:
1. **Modelo de Cifra Simétrica (Seção 2.1):** Uso de uma chave única para ambas as pontas da comunicação.
2. **Técnicas de Substituição (Seção 2.2):** Substituição de elementos do texto claro por outros para gerar o texto cifrado.

## 🚀 Funcionalidades
- **Criptografia:** Transforma um texto legível em um código secreto baseado em um deslocamento (chave).
- **Descriptografia:** Aplica a lógica inversa para recuperar a mensagem original a partir do código cifrado.
- **Interface Web:** Desenvolvida em HTML/CSS e JavaScript puro (Vanilla JS).

## 🛠️ Como usar
1. Insira a mensagem no campo "Texto Original".
2. Defina o valor do deslocamento (Chave).
3. Clique em "Criptografar".
4. Para reverter, clique em "Descriptografar" para ver o texto original retornando ao campo inicial.
